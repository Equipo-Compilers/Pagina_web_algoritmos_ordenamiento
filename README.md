# Descripcion
Este proyecto es una pagina web diseñada para la visualización y comparación de algoritmos de ordenamiento  
específicamente 6 algoritmos de fuerza bruta y 2 de divide y vencerás los cuales son:  
- Bubble Sort
- Insertion Sort
- Selection Sort
- Gnome Sort
- Exchange Sort
- Stooge Sort
- Quick Sort
- Merge Sort
